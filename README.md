# SocietyMS - Digital Society Management System

SocietyMS is a full-stack web application designed to simplify residential society management by bringing resident records, flat management, maintenance payments, expenses, and financial tracking into one platform.

## Features

- **Society Management:** Manage society information and resident-related records.

- **Flat Management:** Maintain flat details and resident assignments.

- **Payment Management:** Track maintenance payments and payment statuses.

- **Payment Proof Uploads:** Store payment screenshots using Cloudinary.

- **Excel Import:** Import flat records from Excel files.

- **Expense Tracking:** Manage society expenses.

- **Financial Summary:** Review payment and financial information.

- **Balance Management:** Track outstanding balances.

- **Gift Management:** Maintain society gift records.

- **Authentication:** Secure access to application features.

## Technology Stack

**Frontend**

- React

- Vite

- Tailwind CSS

**Backend**

- Node.js

- Express.js

- MongoDB with Mongoose

**Integrations**

- MongoDB Atlas

- Cloudinary

- Google Cloud Vision API for OCR

**Deployment**

- Vercel - Frontend

- Render - Backend
